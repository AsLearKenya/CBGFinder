# CBGFinder

梦幻西游藏宝阁搜索、定时任务与估价工具。支持装备、灵饰、上古玉魄、角色、召唤兽及召唤兽装备搜索；提供商品变化记录、复制链接、收藏和按品类估价。

当前应用版本：**V0.8 / 0.8.0**。

## 环境准备

- Node.js 20 或以上版本，附带 npm。
- macOS 或 Windows 桌面环境。安装依赖时需要联网下载 Electron；搜索、登录、验证和材料报价需要访问网易官方服务。
- 本仓库只包含运行、打包所需源码、锁文件和图标，不包含安装依赖、账号、任务、缓存及已打包程序。

```sh
git clone https://github.com/AsLearKenya/CBGFinder.git
cd CBGFinder
npm ci
```

## 启动

桌面版（推荐，支持系统通知、选择数据目录和图片剪贴板）：

```sh
npm run desktop
```

网页版（启动本地服务和官方浏览器请求通道）：

```sh
npm start
```

启动后在浏览器打开 **http://127.0.0.1:5173**。需要桌面环境运行 Electron；不要直接双击 HTML 文件，也不要将本地服务暴露到公网。终端按 `Ctrl+C` 停止。

如默认端口已占用，可停止已有实例或指定其他端口：

```sh
# macOS / Linux shell
PORT=5174 npm start
```

```powershell
# Windows PowerShell
$env:PORT=5174; npm start
```

使用对应端口访问；不同浏览器、端口或桌面版的数据空间相互独立。

## 基本使用

1. 在“角色管理”中添加账号并选择游戏角色。建议使用50级以上的小号；使用高价值账号导致的损失自行承担。
2. 在官方验证窗口中亲自完成将军令、滑块等验证；不需要将验证码填写到其他地方。验证恢复后，同账号已开启任务会立即搜索一次。
3. 在“任务列表”中新建任务，选择绑定角色、商品品类、区服、条件和搜索间隔。可手动搜索、暂停或停止任务。
4. 点击任务查看结果。列表可按价格、含跨服费价格及品类支持的条件排序；跨服费单独显示。上新、价格变化、消失商品单独列出。
5. 装备、灵饰、玉魄可在任务列表独立开启估价。角色进入视窗并停留后加载详情估价；可估价的携带物由用户手动启动。点击估价依据查看样本和计算明细。
6. 在“估价”中粘贴藏宝阁详情链接，可对支持的商品单独估价。在估价设置中调整折扣、材料价值上限、角色及外观价格；材料价格按登录角色所在服务器管理，可手动定价。
7. 在“系统设置”开启系统通知，并在系统权限中允许。商品变化通知另按任务开启。桌面版首次启动提供可跳过的数据目录引导，也可之后在系统设置修改。

估价为规则和样本推算的参考值，不是成交保证。粗略估价、缺少样本和未计价项目会在明细标注。已售出佐证使用缓存的最后挂牌价，不冒充实际成交价。

## 本地数据

- 网页服务的账号、会话及材料等服务端存档默认写入项目 `.data/`；可通过环境变量 `CBG_DATA_DIR` 指定其他目录。
- 网页端任务、浏览基线、已售出佐证等保存在当前浏览器对应站点的本地存储／IndexedDB。清除站点数据会丢失这些记录；服务端数据目录不会替代浏览器存储。
- 桌面版数据位于应用数据目录，可在系统设置选择位置。
- `.data/`、`node_modules/`、`release/` 等均已加入忽略规则；不要提交个人数据或凭据。

## 打包

安装完整依赖后，在相应系统的终端执行：

```sh
# macOS：分别生成 Apple Silicon 和 Intel ZIP
npm run build:mac

# Windows：生成 x64 ZIP
npm run build:win
```

同时构建全部目标：`npm run build:all`。跨平台构建可能需要额外工具；建议各平台在对应系统执行。构建工具首次运行需下载相应平台资源。

当前配置将各平台包分别写入 **`release/V0.8/`**，文件名为 `CBG-Finder-V0.8-平台-架构.zip`。不会将所有平台合并为一个压缩包。

发布新版本时，同步修改 `package.json`、`package-lock.json` 中的应用版本，以及 `build.directories.output`、`build.artifactName` 和本文版本；在新版本目录构建并验证成功后再清理旧发行目录。不要把个人数据加入构建文件列表。

macOS 当前为本地签名配置，未提供 Apple 公证；Windows 未配置代码签名证书。系统首次打开时可能需要用户在安全设置中确认。

## 常见问题

- **安装时下载 Electron 失败**：检查网络与代理，保持终端可访问依赖下载服务后重试 `npm ci`。
- **页面打不开**：确认启动命令仍在运行，访问日志中显示的端口，检查端口是否被占用。
- **提示登录或安全验证**：在程序提供的官方窗口中完成后尝试请求；普通浏览器登录不等于程序内会话已验证。
- **估价较久**：估价与正常搜索分开计时，复用每日材料报价及三小时样本缓存。采样显示分组、页码和完成数；可停止并保留已完成结果。
